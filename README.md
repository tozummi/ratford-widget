# Ratford Bridge Farmhouse Notion Widget

## Add your image
1. Rename your chosen property photograph to `property.jpg`.
2. Put it in the same folder as `index.html`.
3. Upload both files to the root of a GitHub repository.

## Publish with GitHub Pages
1. Open the repository **Settings**.
2. Open **Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Choose the `main` branch and `/ (root)`.
5. Save and wait for the GitHub Pages address to appear.

## Embed in Notion
1. Copy the GitHub Pages address.
2. In Notion, type `/embed`.
3. Paste the address.
4. Resize the embed until the complete card is visible.

The weather cards automatically switch from placeholders to the live forecast
when 17–21 August 2026 enters the supported forecast window.

Weather data supplied by Open-Meteo.

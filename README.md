# Ratford Bridge Farmhouse Notion Widget — Version 2

## Files

- `index.html` — structure and written content
- `styles.css` — colours, layout, mobile styling and animation
- `script.js` — countdown, weather forecast and subtle photo movement
- `property.jpg` — replace this with your selected property image

## Replace the photograph

1. Choose your property photograph.
2. Rename it exactly `property.jpg`.
3. Replace the placeholder image in this folder.
4. Keep the image in the same folder as the HTML file.

A landscape photograph works best. Around 1600 × 1000 pixels is ideal.

## Upload to GitHub

Upload all four files to the root of your GitHub repository:

- index.html
- styles.css
- script.js
- property.jpg

Then open:

**Settings → Pages → Deploy from a branch → main → /(root) → Save**

## Add to Notion

1. Copy your published GitHub Pages link.
2. In Notion, type `/embed`.
3. Paste the link.
4. Increase the embed height until the full widget is visible.

## Built-in features

- Responsive desktop and mobile layout
- Live countdown to 17 August 2026
- Five-day stay forecast
- Elegant custom SVG weather icons
- Check-in and checkout times
- Location and approximate East London drive time
- Guest breakdown
- Gentle photograph movement on supported desktop devices
- Reduced-motion accessibility support

The drive-time line is deliberately written as an approximate range because traffic
and the East London starting point will affect the journey.

Weather data is supplied by Open-Meteo.
